# Tank Trouble 技能说明书

> 当前版本：**v0.2.9** · 共 **26** 种技能，对应英文字母 **A–Z**，每种均有 **加强版**（标记与名称为 `字母+` / `技能名+`）。

场上彩色方块为可拾取物。碰到后：

- **O 护盾 / T 加速**：立即生效，**不占用**武器槽
- **其余 24 种**：装备到当前武器（坦克头顶显示字母），按 **开火键** 释放

| 操作 | 本地 P1 / 联机 | 本地 P2 |
|------|----------------|---------|
| 移动 | WASD | 方向键 |
| 开火 / 释放技能 | 空格 | Enter |

> 默认武器为普通炮弹，每人场上同时最多 **5** 发；撞墙可反弹。**未反弹的自己的子弹打不中自己；反弹后可以击杀自己。**

---

## 加强版（+）

除 26 种基础拾取物外，地图还会刷新 **52 种中的加强版**（标记 `Z+`，金色边框）。

| 效果类型 | 基础 | 加强版 (+) | 适用示例 |
|----------|------|------------|----------|
| 范围 | ×1 | **×1.45** | 冰冻、电磁、空袭、冲击、磁力、漩涡 |
| 持续 | ×1 | **×1.6** | 隐身、伞盾、EMP 眩晕、轨道弹寿命 |
| 数量 | ×1 | **×1.5**（向上取整） | 散弹弹数、加特林弹药、地雷枚数、星爆/雷区碎片 |
| 距离 | ×1 | **×1.35** | 闪现、突进、冲击推力、磁力拉扯 |
| 弹速 | ×1 | **×1.2** | 轨道炮、穿透、重炮、四连 |
| 护盾 | 6 秒 | **9.5** 秒 | O 护盾（即时） |
| 加速 | 5 秒，移速 ×1.65 | **7.5** 秒，移速 **×1.85** | T 加速（即时） |

释放加强版时，坦克上方飘字为 **「技能名+」**（如「冰冻+」），头顶徽章为 **「Z+」**。

## 基础武器

### 普通炮弹

- **获取**：开局默认
- **效果**：向前发射子弹，撞墙反弹（最多约 10 次）
- **限制**：每人场上最多 **5** 发；冷却约 **0.35** 秒
- **自伤**：未反弹前免疫自己；反弹后可自伤

## 各技能详解

### A · 空袭

- **次数**：1
- **效果**：炮口前方约 **160** 处标记轰炸区（半径 **72**），约 **1.1** 秒后爆炸
- **结果**：范围内无护盾的非友军阵亡
- **加强版**：标定更远、范围更大（约 **104**）、延迟略长

### B · 地雷

- **次数**：3 枚（加强版 **5** 枚）
- **效果**：在车**尾**放置地雷
- **机制**：
  1. 放置后约 **0.45** 秒完成布防
  2. **任意坦克（含自己）** 踩到都会触发
  3. 爆炸范围约 **48**，并喷出 **12** 枚三角碎片
- **团战**：队友免疫爆炸，**自己可被自己的雷炸死**

### C · 重炮

- **次数**：1
- **效果**：发射半径 **9**、弹速 **180** 的重型炮弹，弹跳次数多
- **加强版**：弹体更大、弹速 ×1.2

### D · 死光

- **次数**：1
- **效果**：瞬时光束，类似激光但可 **穿透** 多个目标；反射最多约 **10** 次
- **辅助**：装备期间显示瞄准线
- **区别**：激光打中第一个有护盾的目标后停止；死光可继续（护盾仍挡并中断）
- **加强版**：更多反射次数

### E · 电磁脉冲

- **次数**：1
- **效果**：半径 **130** 脉冲，对非友军：
  - 清空武器（含加强版标记）
  - 清除加速
  - 附加约 **0.6** 秒冰冻
- **加强版**：范围约 **188**，眩晕约 **1** 秒

### F · 破片

- **次数**：1（两段操作）
- **效果**：
  1. 第一次开火：打出较慢的破片弹
  2. **再次开火**：手动引爆 → **14** 枚三角碎片
  3. 超时未引爆也会自动爆炸
- **注意**：碎片可伤自己，团战可误伤队友

### G · 加特林

- **次数**：28 发（加强版 **42** 发）
- **效果**：按住开火连射（冷却约 **0.07** 秒/发），弹速 **320**
- **用尽**：回到普通炮弹

### H · 追踪

- **次数**：1
- **效果**：发射追踪最近非友军的导弹，可拐弯、可反弹
- **团战**：不锁定队友

### I · 隐身

- **次数**：1
- **效果**：约 **2.2** 秒（加强版约 **3.5** 秒）内敌方子弹无法命中
- **外观**：坦克半透明

### J · 突进

- **次数**：1
- **效果**：沿炮口短冲约 **90** 距离，遇墙停下
- **对比**：比 **W 闪现** 距离短、冷却更快

### K · 冲击

- **次数**：1
- **效果**：半径 **100** 内将敌人推开（推力 **55**）
- **加强版**：范围约 **145**，推力约 **74**

### L · 激光

- **次数**：1
- **效果**：瞬时光束，沿墙反射最多 **8** 次（加强版约 **12** 次）
- **命中**：碰到敌方即击杀；有护盾则无效并中断
- **辅助**：装备期间显示瞄准线

### M · 磁力

- **次数**：1
- **效果**：半径 **110** 内将敌人向自己拉扯约 **70** 距离
- **加强版**：范围约 **160**，拉扯约 **95**

### N · 星爆

- **次数**：1
- **效果**：以自身为中心喷出 **16** 枚三角弹（加强版 **24** 枚）
- **用途**：近身清场；碎片可伤自己及队友

### O · 护盾

- **持续**：**6** 秒（加强版 **9.5** 秒）
- **效果**：抵挡子弹 / 激光 / 地雷 / 空袭；被普通弹击中时子弹反弹
- **外观**：青色护盾环
- **即时生效**，不占武器槽

### P · 穿透

- **次数**：1
- **效果**：发射可连续击穿 **2** 名敌人（加强版 **3** 名）的炮弹
- **加强版**：弹速 ×1.2

### Q · 四连

- **次数**：1
- **效果**：一次扇形打出 **4** 发普通炮弹
- **加强版**：扇形更宽、弹速更快

### R · 轨道炮

- **次数**：1
- **效果**：超高速（**520**）直线弹，存活约 **1.4** 秒
- **加强版**：弹速 ×1.2，存活约 **2.2** 秒

### S · 散弹

- **次数**：3 次，每次 **7** 发（加强版每次 **11** 发）
- **效果**：扇形铅弹，Spread 约 **0.45** rad（加强版约 **0.56**）

### T · 加速

- **持续**：**5** 秒（加强版 **7.5** 秒）
- **效果**：移速 ×**1.65**、转向 ×**1.35**（加强版 ×**1.85** / ×**1.5**）
- **外观**：橙色环
- **即时生效**；可被 **E 电磁** 清除

### U · 伞盾

- **次数**：1 → 持续 **4.5** 秒（加强版约 **7.2** 秒）
- **效果**：炮口**前方扇形**（约 **1.35** rad）反弹来袭子弹
- **区别**：**O 护盾**为全身圆形；伞盾仅前方，可与护盾叠加

### V · 漩涡

- **次数**：1
- **效果**：半径 **95** 内敌人被拉向中心，并冰冻约 **1** 秒
- **加强版**：范围约 **138**，冰冻约 **1.6** 秒

### W · 闪现

- **次数**：1
- **效果**：沿炮口瞬移最多 **140** 距离，遇墙提前停下
- **加强版**：约 **189** 距离

### X · 分裂

- **次数**：1
- **效果**：射出一发炮弹；**首次撞墙**后分裂为 **3** 枚三角弹（加强版 **5** 枚）
- **注意**：碎片可伤自己及队友

### Y · 雷区

- **次数**：1
- **效果**：在身后扇形一次性布置 **5** 枚地雷（加强版 **8** 枚）
- **机制**：与 **B 地雷** 相同（可自踩、爆炸 + 碎片）

### Z · 冰冻

- **次数**：1
- **效果**：以自身为中心半径 **110**，冰冻非友军约 **2.4** 秒
- **结果**：无法移动 / 转向 / 开火
- **加强版**：半径约 **160**，约 **3.8** 秒
- **不冻自己**；团战不冻队友

## 模式相关

### 经典模式

- 最多 **4** 人混战，先到 **5** 分
- 范围技能不误伤自己；反弹弹 / 碎片 / 地雷仍可能自尽

### 超多人模式

- **6 / 8** 人，红蓝两队，先到 **10** 局胜
- **队友免疫**：普通弹 / 追踪 / 激光 / 地雷爆炸 / 空袭 / 冰冻 / EMP / 冲击 / 磁力 / 漩涡 等
- **例外**：破片 / 星爆 / 分裂 的 **三角碎片可误伤队友**

---

## 拾取与替换规则

1. 地图每约 **7** 秒尝试刷新拾取物（经典最多 **3** 个，超多人 **5** 个）
2. 拾取池含 **52** 种（26 基础 + 26 加强），随机刷新
3. 捡到新武器会**替换**当前武器（含是否为加强版）
4. **O 护盾 / T 加速** 为独立计时器，捡到即刷新
5. 武器类技能用尽后回到普通炮弹
