# 游戏说明

Tank Trouble 是一款 **2D 迷宫坦克对战** 游戏。玩家在随机生成的迷宫内移动、转向、发射会反弹的炮弹，利用角度与反弹击杀对手。

## 胜负规则

- 击杀一名对手 → 得 **1** 分
- 得分后进入 **下一小局**：新迷宫、出生点打乱（自定义地图试玩时地图不变）
- **经典模式**：最多 4 人，默认先到 **5** 分获胜（创建房间可改）
- **超多人模式**：6 或 8 人红蓝两队，默认先到 **10** 局获胜（创建房间可改）

## 炮弹规则

- 每人场上同时最多 **5** 发普通炮弹
- 炮弹撞墙会反弹（最多约 10 次）
- **未反弹**的自己的炮弹不会命中自己
- **反弹后**的自己的炮弹可以击杀自己

## 技能系统

场上周期性刷新彩色方块拾取物：

- **O 护盾 / T 加速**：捡到立即生效，不占武器槽
- **其余技能**：装备到武器槽，按开火键释放，用完回到普通炮弹
- 共 **26** 种字母技能，每种还有 **+** 加强版

详见 [技能大全](/game/skills) 与 [技能速查表](/game/skill-grid)。

## 音效

- 主菜单与对战各有 **旋律背景音乐**（程序化合成音符循环，无需下载资源）
- **开火**、**坦克移动**、**反弹**、**拾取**、**死亡/爆炸**、小局结束均有音效
- **26 种技能**释放时音效各不相同（与技能飘字同步触发）
- 首次点击或按键后浏览器才允许播放音频

## 局内聊天

- 对战中按 **Enter** 或 **T** 打开聊天面板（未打开时不显示聊天栏）
- 发出的快捷语与文字会在对应坦克头顶以**气泡**显示约 4 秒
- 可输入文字，或点击 **快捷语** 一键发送
- **超多人红蓝对阵**：可切换 **全员** / **阵营** 频道（Tab 或按钮）
- 联机时阵营消息仅同队可见；本地模式同样支持分频道练习

## 联机

- 创建房间获得 4 位房间码，好友输入同一码加入；**胜利积分**可在主菜单或等待大厅设定
- **房间大厅**可浏览等待中的房间并点击进入
- 支持**多房间同时存在**，不同组用不同房间码
- 联机采用 **60Hz 权威服 + 输入回放 + tick 内插值**（`onlinePrediction.ts`），兼顾跟手、顺滑与开火/拾取一致
- [远程联机说明](/guide/multiplayer)

## 模式对比

| | 经典 | 超多人 |
|---|------|--------|
| 人数 | ≤4 | 6 或 8 |
| 队伍 | 无 | 红蓝两队 |
| 胜利 | 默认 5 分（可自定义） | 默认 10 局（可自定义） |
| 地图 | 固定 | 随局数增大（有上限） |
| 友军免疫 | 仅自己 | 队友免疫多数技能 |

**单人 + AI**：本地一人对战 AI；对战中或结算页按 **R** 可立刻重开本场。
