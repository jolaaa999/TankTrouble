## 加强版规则

拾取物或坦克徽章上的 **`+`** 表示加强版，例如 **Z+** = 冰冻+。

| 类型 | 加强倍率 |
|------|----------|
| 范围 | ×1.45 |
| 持续 | ×1.6 |
| 数量 | ×1.5（向上取整） |
| 距离 | ×1.35 |
| 弹速 | ×1.2 |

## 即时增益（不占武器槽）
