# 游戏模式

## 经典模式

- **人数**：1–4（可 AI 填充，默认关闭）
- **胜利**：默认先到 **5** 分；创建房间时可在主菜单或等待大厅切换（预设 3/5/7/10/15/20/30）
- **地图**：11×7 格（固定）
- **拾取上限**：场上约 **3** 个

范围技能（冰冻、EMP 等）不会误伤自己；反弹弹、碎片、地雷仍可能**自尽**。

## 超多人模式（Mega）

- **人数**：6 或 8
- **队伍**：红蓝两队
- **胜利**：默认先到 **10** 局；创建房间时可自定义
- **地图**：随局数缓慢变大，封顶 **15×10**（适配浏览器画布）
- **拾取上限**：场上约 **5** 个

### 团战规则

**队友免疫**（不会误伤）：

- 普通弹 / 铅弹 / 追踪 / 激光 / 死光
- 地雷爆炸 / 空袭 / 冰冻 / EMP / 冲击 / 磁力 / 漩涡

**例外**（碎片可误伤队友）：

- 破片弹引爆的三角碎片
- 星爆 / 分裂产生的碎片

自己的反弹弹仍可击杀自己；自己的地雷可炸死自己。

## 本地双人

同一浏览器，P1 用 WASD+空格，P2 用方向键+Enter，无需联网。

## 单人 + AI

主菜单 **单人 + AI**：一人对战机器人。对战中或结算页按 **R** 可重开本场（保留经典/超多人与席位设置）。

## 联机房间

- 按 **roomCode** 隔离，可多组同时对战
- 创建前在主菜单设定**胜利积分**；等待中仍可点击按钮切换
- 全员 **R** 准备后开始
- 对战中 **Enter / T** 打开聊天面板；消息在坦克头顶以气泡显示（超多人可分阵营频道）
- 详见 [远程联机](/guide/multiplayer)
