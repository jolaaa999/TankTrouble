# 地图编辑器

<span class="version-pill">v0.3.0</span> · 本地试玩自定义迷宫

主菜单点击 **地图编辑器** 进入。可绘制墙壁、摆放出生点，并在本地 **试玩** 自定义地图（含 AI 对手）。

## 工具栏

| 按钮 | 说明 |
|------|------|
| **墙壁** | 点击格子**边线**切换横/竖墙 |
| **出生点** | 点击格子中心添加或移除出生点（至少 **2** 个才能试玩） |
| **随机** | 用算法生成一张新迷宫 |
| **保存** | 写入浏览器 `localStorage`，下次打开自动加载 |
| **导出** | 复制 JSON 到剪贴板，便于分享或备份 |
| **导入** | 粘贴 JSON 覆盖当前地图 |
| **试玩** | 进入本地对战（固定使用当前地图，每局不重新随机） |
| **列± / 行±** | 调整地图尺寸（**5–15** 列 × **5–10** 行） |
| **清空** | 移除所有内部墙壁（保留外框） |

按 **ESC** 或点 **返回** 回到主菜单。

## 地图 JSON 格式

```json
{
  "name": "我的地图",
  "cols": 11,
  "rows": 7,
  "hWalls": [[true, false, ...]],
  "vWalls": [[true, false, ...]],
  "spawns": [{ "x": 32, "y": 32 }]
}
```

- `hWalls`：`(rows + 1) × cols`，每格顶边是否有墙
- `vWalls`：`rows × (cols + 1)`，每格左边是否有墙
- `spawns`：出生点中心坐标（像素）

## 限制与说明

- 自定义地图目前仅支持 **本地试玩**，联机房间仍使用随机迷宫
- 试玩时地图布局**固定不变**（得分后不会换图，只打乱出生顺序）
- 与超多人模式不同，自定义地图**不会**随局数缩放
