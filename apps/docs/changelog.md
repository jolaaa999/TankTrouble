# 更新日志

## v0.3.10

- **局内聊天**：离开对局后彻底销毁聊天 UI/快捷键；修复面板打开时 **Esc 无法关闭**（焦点不在输入框时也能关）

## v0.3.9

- **联机移动手感**：本地坦克改为持续预测；校正时不再沿前进方向回拉（消除前进/后退一顿一顿）；远端坦克去掉过冲外推

## v0.3.8

- **联机前进/后退**：改为从服务端快照外推（去掉橡皮筋式校正），移动更顺滑；移动时输入每帧发送

## v0.3.7

- **联机延迟优化**：服务端 tick 提升至 **60Hz**；本地坦克 **客户端预测**（即时跟手）；输入 60Hz 发送；远端坦克轻微外推

## v0.3.6

- **激光**改用连续碰撞检测，修复穿墙（穿模）问题；瞄准线同步修正
- **联机**客户端在 60fps 下对坦克位置插值、子弹外推，渲染与网络同步解耦，减轻卡顿感

## v0.3.5

- **局内聊天**：未打开面板时不显示聊天栏；消息在对应坦克头顶以**气泡**展示（快捷语与文字消息均如此）
- **背景音乐**改为旋律循环（菜单轻快、对战紧张），去掉对战 BGM 中的白噪声铺底

## v0.3.4

- **局内聊天**：Enter / T 打开，可打字或点选快捷语
- **超多人模式**支持 **全员** / **阵营** 分频道发言（联机由服务端转发）

## v0.3.3

- **单人 + AI**：对战中与结算页均可按 **R** 重开本场（保留模式/席位设置）

## v0.3.2

- **房间大厅**：浏览等待中的房间列表，点击进入加入
- 服务端 `GET /rooms` 返回可加入房间（房间码、模式、人数、AI 设置）

## v0.3.1

- 新增程序化 **音效与背景音乐**（Web Audio，无需外部音频文件）
- 开火、移动、反弹、拾取、死亡爆炸、小局结束均有音效
- **26 种技能**释放时各自不同的音效（通过技能飘字触发）

## v0.3.0

- **迷宫地图编辑器**：主菜单进入，墙壁/出生点绘制、随机生成、本地保存
- 支持 JSON **导入/导出** 与 **试玩**（本地 + AI，固定地图）
- 地图尺寸 **5–15** 列 × **5–10** 行
