# Tank Trouble 技能说明书

场上彩色方块为可拾取物。碰到后：

- **护盾 / 加速**：立即生效，不占用武器槽
- **其余技能**：装备到当前武器（坦克头顶字母标记），按 **开火键** 使用

| 操作 | 本地 P1 / 联机 | 本地 P2 |
|------|----------------|---------|
| 移动 | WASD | 方向键 |
| 开火 / 释放技能 | 空格 | Enter |

> 默认武器为普通炮弹，场上同时最多 5 发；撞墙可反弹，**反弹后的自己的子弹也能击杀自己**。

## 基础武器

### 普通炮弹

- **获取**：开局默认，无拾取物
- **效果**：向前发射黑色子弹，撞墙反弹（最多约 10 次）
- **限制**：每人场上同时最多 **5** 发；开火冷却约 **0.35** 秒
- **自伤**：未反弹前打不中自己；**反弹后可以击杀自己**

---

## 武器类拾取（开火消耗）

### L · 激光（Laser）

- **次数**：1
- **效果**：瞬时光束，沿墙壁反射最多 **8** 次
- **命中**：碰到敌方坦克即击杀（有护盾则无效并中断）
- **辅助**：装备期间显示瞄准辅助线
- **注意**：不是飞行子弹，开火瞬间结算

### S · 散弹（Shotgun）

- **次数**：3
- **效果**：一次打出 **7** 发扇形铅弹
- **特点**：近距离覆盖面大，弹速与普通弹接近
- **用尽**：弹药打完后回到普通炮弹

### G · 加特林（Gatling）

- **次数**：28
- **效果**：按住开火连射高速小弹（冷却约 **0.07** 秒）
- **特点**：压制力强，单发伤害仍为一击毙命
- **用尽**：弹药打完后回到普通炮弹

### H · 追踪弹（Homing）

- **次数**：1
- **效果**：发射一枚会转向的导弹，追逐最近的非友军坦克
- **特点**：可在迷宫中拐弯；仍会撞墙反弹
- **注意**：团战模式下不会锁定队友

### B · 地雷（Booby）

- **次数**：3
- **效果**：在车**尾**放置地雷
- **机制**：
  1. 放置后约 **0.45** 秒完成布防
  2. 任意坦克踩到触发，短暂延迟后爆炸
  3. 爆炸半径约 **48**，范围内无护盾坦克阵亡
- **友军**：团战中不会炸死队友（自己是否踩雷取决于是否算友军判定；经典混战下自己也能踩爆）

### F · 破片（Frag）

- **次数**：1（两段操作）
- **效果**：
  1. 第一次开火：打出一枚较慢的黄色炸弹弹
  2. **再次开火**：手动引爆 → 向四周弹出 **10** 枚碎片
  3. 若不手动引爆，炸弹存活结束也会自动炸开
- **特点**：碎片可伤及自己，适合墙角伏击

### D · 死光（Death Ray）

- **次数**：1
- **效果**：类似激光的瞬时光束，反射次数更多，且可 **穿透** 多个目标
- **辅助**：同样显示瞄准线
- **区别**：激光打中第一个目标后停止；死光可继续穿透（护盾仍可挡住并中断）

## 立即生效增益

### + · 护盾（Shield）

- **持续**：约 **6** 秒
- **效果**：
  - 抵挡子弹 / 激光 / 地雷爆炸 / 空袭等致命伤害
  - 被普通类子弹打中时，子弹会反弹并消耗一次弹跳计数
- **外观**：坦克周围青色护盾环
- **不占**武器槽，可与当前武器并存

### T · 加速（Turbo）

- **持续**：约 **5** 秒
- **效果**：移动速度 ×**1.65**，转向 ×**1.35**
- **外观**：橙色环
- **立即生效**，不占武器槽
- **克制**：可被敌方 **E 电磁脉冲** 清除

---

## 主动技能（装备后开火释放）

### Z · 冰冻（Freeze）

- **次数**：1
- **效果**：以自身为中心、半径约 **110** 的范围冰冻
- **结果**：范围内非友军坦克约 **2.4** 秒无法移动/转向/开火
- **友军**：团战不冻队友；不会冻自己

### W · 闪现（Blink）

- **次数**：1
- **效果**：沿当前炮口朝向瞬移最多约 **140** 距离
- **机制**：遇墙会提前停下，不会穿墙
- **用途**：越墙角、拉开距离、追击残局

### E · 电磁脉冲（EMP）

- **次数**：1
- **效果**：半径约 **130** 的脉冲
- **结果**（对非友军）：
  - 清空对方当前武器，回到普通炮弹
  - 清除对方加速状态
  - 附加约 **0.6** 秒短暂冰冻
- **用途**：反制激光 / 加特林 / 加速等强势状态

### A · 空袭（Airstrike）

- **次数**：1
- **效果**：在炮口前方约 **160** 处标记轰炸区（半径约 **72**）
- **延迟**：约 **1.1** 秒后爆炸
- **结果**：范围内无护盾的非友军坦克阵亡
- **注意**：标定点按释放瞬间的位置与朝向计算，释放后可自己躲开

## 模式相关

### 经典模式

- 最多 4 人混战，先到 **5** 分
- 无队伍，上述「友军」仅指自己（技能不会误伤自己的范围技，但反弹弹/碎片/地雷仍可能自尽）

### 超多人模式

- 6 / 8 人，红蓝两队，先到 **10** 局胜
- **队友免疫**：普通弹 / 铅弹 / 追踪 / 激光 / 地雷爆炸 / 空袭 / 冰冻 / EMP
- **例外**：破片弹炸开的 **碎片可以误伤队友**；自己的反弹弹仍可击杀自己
- 范围技能（冰冻 / EMP）不会作用于自己或队友

---

## 拾取与替换规则

1. 地图会周期性刷出拾取物（经典最多约 3 个，超多人最多约 5 个）
2. 捡到新的**武器/技能**会**替换**当前未用完的武器
3. 护盾、加速为独立计时器，捡到即刷新/覆盖对应增益
4. 技能用完后自动回到普通炮弹
