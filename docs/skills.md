# Tank Trouble 技能说明书

场上彩色方块为可拾取物。每个技能对应 **A–Z 其中一个字母**；拾取物上可能带 **金色边框** 与 **`字母+`** 标记，表示 **加强版**（效果更强，释放时飘字为「技能名+」，如「冰冻+」）。

碰到后：

- **护盾 (O) / 加速 (T)**：立即生效，不占用武器槽
- **其余技能**：装备到当前武器（坦克头顶字母标记），按 **开火键** 使用

| 操作 | 本地 P1 / 联机 | 本地 P2 |
|------|----------------|---------|
| 移动 | WASD | 方向键 |
| 开火 / 释放技能 | 空格 | Enter |

> 默认武器为普通炮弹，场上同时最多 5 发；撞墙可反弹，**反弹后的自己的子弹也能击杀自己**。

---

## 加强版（+）

地图上除 26 种基础技能外，还会刷新对应的 **加强版拾取物**（标记为 `X+`）。

| 属性 | 基础 | 加强版 (+) |
|------|------|------------|
| 范围类（冰冻、EMP、空袭等） | 标准 | 约 **×1.45** |
| 持续类（隐身、伞盾、眩晕等） | 标准 | 约 **×1.6** |
| 数量类（散弹、地雷、星爆碎片等） | 标准 | 约 **×1.5**（向上取整） |
| 距离类（闪现、突进、冲击等） | 标准 | 约 **×1.35** |
| 弹速类（轨道炮、穿透等） | 标准 | 约 **×1.2** |
| 护盾持续 | 约 6 秒 | 约 **9.5** 秒 |
| 加速持续 / 倍率 | 5 秒 / ×1.65 | 约 **7.5** 秒 / **×1.85** |

释放加强版技能时，坦克上方会弹出中文名并带 **+** 后缀。

## 新增技能说明

### I · 隐身

- 释放后约 **2.2** 秒（加强版更久）内，敌方子弹无法命中你
- 坦克半透明显示

### J · 突进

- 沿炮口短距离冲刺（约 **90** 距离），遇墙停下
- 比 **W 闪现** 距离短、冷却更快

### K · 冲击

- 以自身为中心推开范围内敌人（加强版范围与推力更大）

### M · 磁力

- 将范围内敌人向自己方向拉扯一段距离

### P · 穿透

- 发射可击穿 **2** 名敌人（加强版 **3** 名）的炮弹

### Q · 四连

- 一次扇形打出 **4** 发普通炮弹

### U · 伞盾

- 释放后约 **4.5** 秒（加强版更久）内，**炮口前方扇形** 可反弹来袭子弹
- 与 **O 护盾**（全身）不同，不占武器槽冲突时可叠加思考

### V · 漩涡

- 范围内敌人被拉向中心并短暂冰冻

### X · 分裂

- 射出一发炮弹；**首次撞墙** 后分裂为 **3**（加强版 **5**）枚三角碎片

### Y · 雷区

- 在身后扇形一次性布置 **5** 枚地雷（加强版更多）

## 经典技能（加强版规则同上）

### L · 激光 / D · 死光

- 激光：反射光束，打中首个目标停止（加强版反射更多次）
- 死光：可穿透多个目标

### B · 地雷 / F · 破片 / N · 星爆

- 地雷与雷区：爆炸 + 三角碎片；**自己可踩爆**
- 破片：慢弹，再按开火手动引爆
- 星爆：近身一圈三角弹

### Z · 冰冻 / W · 闪现 / E · 电磁 / A · 空袭

- 冰冻：范围定身（加强版范围更大、更久）
- 闪现：长距离瞬移（加强版更远）
- 电磁：清武器、清加速、短眩晕
- 空袭：前方延迟轰炸（加强版范围更大）

### O · 护盾 / T · 加速

- 捡到即生效，不占武器槽
- 加强版：护盾更久；加速更久且移速更高

## 模式相关

### 经典模式

- 最多 4 人混战，先到 **5** 分
- 范围技能不会误伤自己；反弹弹 / 碎片 / 地雷仍可能自尽

### 超多人模式

- 6 / 8 人，红蓝两队，先到 **10** 局胜
- **队友免疫**：普通弹 / 追踪 / 激光 / 地雷爆炸 / 空袭 / 冰冻 / EMP 等
- **例外**：破片 / 星爆 / 分裂 的 **碎片可误伤队友**

---

## 拾取与替换规则

1. 地图周期性刷新拾取物（经典约 3 个，超多人约 5 个）；池中含 **52** 种（26 基础 + 26 加强）
2. 捡到新武器会**替换**当前未用完的武器（含是否加强版）
3. 护盾、加速为独立计时器，捡到即刷新
4. 技能用完后回到普通炮弹
